A **host** is any computer running `goattyd`. goatty can open tabs on other hosts next to your local ones, and each remote tab behaves like a local one: its shells keep running when you disconnect, and you can detach, reattach and use [workspaces](/docs/using/tabs-workspaces) there too.

Rendering stays on your GPU. Only the terminal stream travels, so it stays usable on slow links.

## Connect over SSH

Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>, then pick a host or type `user@host`. From a terminal: `goatty --ssh myserver`.

goatty uses your normal `ssh`, so your `~/.ssh/config`, keys, agent, `ProxyJump` and Tailscale SSH all work. Passphrase and host key prompts show up in a small goatty dialog.

**The first time**, if the host has no goattyd, goatty offers to install it. It's copied to `~/.local/share/goatty/bin` after you confirm, needs no `sudo`, and changes nothing else on the host. Windows hosts work too (goattyd goes to `%LOCALAPPDATA%\goatty\bin`). goatty also offers **Update and restart** when the host's goattyd is too old.

Manage hosts under [Settings → Hosts](goatty://settings/hosts):

- add a host as `user@host` or a name from your `~/.ssh/config`, with an optional display name and a [tab color](goatty://settings/hosts?setting=ssh.hosts);
- [list the hosts](goatty://settings/hosts?setting=ssh.discover) already in your `~/.ssh/config`;
- choose whether a host [opens in a new window or a new tab](goatty://settings/hosts?setting=ssh.open_in). In the session list, <kbd>Shift</kbd>+<kbd>Enter</kbd> does the other one.

### Plain SSH

If you don't want anything installed on a host, choose **Plain SSH** (or `goatty --ssh host --plain`). It's just `ssh host` inside a local session. The session survives closing the window, but not a network drop, and none of goatty's shell setup reaches the host. You can set it per host on the Hosts page.

### Other ways in

Anything that can run `goattyd proxy` works:

```bash
goatty --via 'docker exec -i devbox goattyd proxy'
goatty --via 'wsl.exe -d Ubuntu -- goattyd proxy'     # Windows → WSL
```

## Connect over Tailscale

Tailscale pairing connects two computers on your tailnet without SSH. goatty uses the Tailscale you already installed and logged in to. It never installs it, logs in, or runs `sudo`, and goattyd opens no network port of its own.

<Steps>
1. **Make the other computer available.**

   On the computer you want to reach: [Settings → Network → Make this computer available](goatty://settings/network). On a server without a screen, run `goattyd net enable`.

2. **Pair.** Pick the situation that fits:

   - **Two computers with screens:** on the host, choose **Allow a new device** (it opens a 5-minute window). On the other computer press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>, pick the host, and confirm the 6-digit code on both screens.
   - **Headless server or VPS:** run `goattyd net pair` there. It prints a one-time code. Paste it into [Settings → Network](goatty://settings/network), or run `goatty net pair <code>` on your computer.
   - **A host you can reach over SSH right now:** `goatty net pair --ssh myserver` sets everything up over that connection. Or use **Pair over Tailscale** on the Network page.
</Steps>

From then on the host appears like any other, by its Tailscale name. Connect with <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> or `goatty --tailnet myserver`.

[**Network**](goatty://settings/network) shows Tailscale's state, the devices paired with this computer (you can revoke them) and the hosts it paired with. `goatty net list` and `goattyd net status` show the same in a terminal.

<Aside type="note" title="If Tailscale asks for permission">
  Making a computer available adds one `tailscale serve` route. If Tailscale doesn't allow your user to do that yet, goatty shows the single command that fixes it (on Linux: `sudo tailscale set --operator=$USER`). It never runs it for you.
</Aside>

## Staying connected

- **Reconnect.** If the link drops, goatty retries by itself and the title shows *reconnecting*. Your shells kept running on the host.
- **Slow links.** goatty can show what you type before the host echoes it back. The [setting](goatty://settings/hosts?setting=ssh.local_echo) is *auto* by default: it turns on when the host is slow enough to notice.
- **Several hosts at once.** One window can hold tabs on many hosts. New tabs and splits open on the same host as the one you're in. Tabs are grouped under each host's name.

## Working on a remote host

- **Settings follow the tab.** The shell pages (Prompt, Aliases, Plugins …) edit the host of the tab you're in. The scope picker at the top shows which. Window settings such as fonts and shortcuts stay on your computer.
- **Clipboard:** use `copy` to put text on *your* clipboard, see [Terminal basics](/docs/using/terminal#copy-from-a-remote-host).
- **Files:** Ctrl+click on a remote file opens a read-only copy, or opens it in your editor over SSH. See [Open remote files with](goatty://settings/terminal?setting=links.remote_file_opener).
- **Same shell everywhere:** goatty can keep your prompt, aliases and plugins in sync across hosts. See [Sync across hosts](/docs/customize/sync).

For the design behind this, see the technical docs on GitHub: [tailnet](https://github.com/goatty-dev/goatty/blob/main/docs/tailnet.md) and [remote architecture](https://github.com/goatty-dev/goatty/blob/main/docs/remote-architecture.md).
