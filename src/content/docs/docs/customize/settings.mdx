Open Settings with <kbd>Ctrl</kbd>+<kbd>,</kbd>. Press <kbd>/</kbd> (or <kbd>Ctrl</kbd>+<kbd>F</kbd>) to search every setting by its name or by what it does. Throughout these docs, links such as [Open links](goatty://settings/terminal?setting=links.open_on) jump straight to a setting in your running goatty. See [goatty:// links](/docs/reference/links).

## The pages

| Page | What it controls |
| --- | --- |
| [**Appearance**](goatty://settings/appearance) | Themes (one, or light and dark following your desktop), fonts, size, cursor, padding, opacity and blur, title bar. |
| [**Terminal**](goatty://settings/terminal) | Links, selection and copy, paste protection, right click, scrolling. |
| [**Workspace**](goatty://settings/workspace) | What starts, tab style, program icons, notifications. |
| [**Shortcuts**](goatty://settings/shortcuts) | Every action and its keys, plus your own commands. |
| [**Hosts**](goatty://settings/hosts) and [**Network**](goatty://settings/network) | [SSH and Tailscale hosts](/docs/using/remote-hosts), and the [shared shell config](/docs/customize/sync). |
| [**Shell**](goatty://settings/shell), [**Dotfiles**](goatty://settings/dotfiles), [**PATH**](goatty://settings/path) | The [managed shell](/docs/using/managed-zsh), what's imported from your setup, PATH folders. |
| [**Prompt**](goatty://settings/prompt), [**History**](goatty://settings/history) | The Starship prompt and shell history. |
| [**Aliases**](goatty://settings/aliases) | Your aliases, and the ones plugins add. |
| [**Snippets**](goatty://settings/snippets) | [Snippets & expansions](/docs/using/snippets). |
| [**Plugins**](goatty://settings/plugins) | [Browse, install and configure plugins](/docs/customize/plugins). |
| [**Diagnostics**](goatty://settings/diagnostics) | A health report for the shell on the current host. |
| [**Profile**](goatty://settings/profile) | Problems, file locations, export and import, version history. |

## Two kinds of settings

| | Window settings | Shell settings |
| --- | --- | --- |
| **Pages** | Appearance, Terminal, Workspace, Shortcuts, Hosts, Network | Shell, Dotfiles, PATH, Prompt, History, Aliases, Snippets, Plugins |
| **Lives on** | the computer you're sitting at | each host (every machine running `goattyd`) |
| **File** | `settings.json` | `host.json` (plus the [shared config](/docs/customize/sync)) |
| **Applies** | immediately | after Preview → Apply |

The files are in `~/.config/goatty/` (`%APPDATA%\goatty` on Windows). They're readable JSON, and only values that differ from the defaults are written, so improved defaults reach you automatically. Find the exact paths on the Profile page.

When you're in a tab on another host, the shell pages show *that* host's settings.

## Themes

[Appearance](goatty://settings/appearance?setting=theme.follow_system) has a theme gallery. Pick one theme, or turn on **Follow the system** and assign a light and a dark theme.

- **Import** color schemes in base16 (YAML or JSON), iTerm2 `.itermcolors` or Windows Terminal format. From a terminal: `goatty theme import file`.
- **Customize colors** opens a color editor with contrast checks. Save the result as your own theme, or clear the changes.
- Put a theme file in `~/.config/goatty/themes/` and it shows up in the gallery.

## Preview, then apply

Window settings change live. Shell settings are collected in a draft first:

<Steps>
1. Change settings on any shell page.

   Pages with unapplied changes are marked in the sidebar.

2. Choose **Preview**.

   goatty shows a colored diff of the files it would generate.

3. Choose **Apply**, or **Discard**.

   Apply checks the new configuration first. If it's invalid, nothing changes.

4. Choose **Reload running shells** when offered.

   Existing shells pick up the change at their next idle prompt.
</Steps>

## Roll back

Every applied change is a **generation**. On the [Profile page](goatty://settings/profile) you can see what each one changed, name them (say, "before trying fish"), and roll back to any of the last 10. From a terminal:

```bash
goattyd shell generations     # list them
goattyd shell diff 8          # what changed in generation 8
goattyd shell name 8 before trying fish
goattyd shell rollback        # go back to the previous one
```

Rolling back also restores the settings that generation was built from.

## Profiles: export and import

**Profile → Export** writes your settings to one file, with only non-default values and without machine-specific ones. **Import** applies the window settings right away and stages the shell part as a draft for you to preview and apply. That's a quick way to set up a new computer. To keep *shells* in step across machines continuously, use [Sync across hosts](/docs/customize/sync) instead.

## When something is wrong

If a value in a settings file is invalid, goatty reverts just that value to its default and says so: on the row, in a toast, and on the Profile page, which lists every problem with a **Show** button that jumps to it. The rest of your settings are kept, and the file is left untouched.

Environment variables such as `GOATTY_FONT_SIZE` override a setting for one run. The row then says *Set by GOATTY_FONT_SIZE for this run* and is disabled.

## From the command line

Everything also works without a window, which suits scripts, SSH sessions and dotfile repos:

```bash
goatty settings show font          # what's stored for a key
goatty settings set font.size 15   # a running goatty picks it up within a moment
goatty settings unset font.size
goatty settings validate           # exit code 1 on problems
goatty settings export profile.json
goatty settings import profile.json --ssh myserver   # the shell part goes to that host
goatty theme list
goatty theme set nord --for dark
```

`goattyd settings …` does the same for a host's shell settings. See the [command reference](/docs/reference/cli).
