goatty is a fast GPU terminal for Linux and Windows (macOS is planned). It comes with a ready-to-use shell, a settings window for everything, and sessions that keep running when you close the window.

## Install

<Tabs>
  <TabItem label="Windows" icon="seti:windows">
    Windows 10/11 (x86_64). Download from the [latest release](https://github.com/goatty-dev/goatty/releases/latest) and use either:

    - **`goatty-<version>-x86_64-windows.msi`** installs for your user only, with no administrator rights. It adds goatty to your `PATH` and the Start Menu. Uninstall it from *Settings → Apps*.
    - **`goatty-<version>-x86_64-windows.zip`**: extract anywhere and run `goatty.exe`.

    The builds aren't code-signed yet, so SmartScreen may warn you. Choose *More info → Run anyway*.
  </TabItem>

  <TabItem label="Arch Linux" icon="linux">
    From the AUR:

    ```bash
    paru -S goatty-bin    # or: yay -S goatty-bin
    ```
  </TabItem>

  <TabItem label="Ubuntu / Debian" icon="linux">
    Ubuntu 22.04+ and Debian 12+. Download the `.deb` from [GitHub Releases](https://github.com/goatty-dev/goatty/releases):

    ```bash
    sudo apt install ./goatty_<version>-1_amd64.deb
    ```
  </TabItem>

  <TabItem label="Fedora" icon="linux">
    Download the `.rpm` from [GitHub Releases](https://github.com/goatty-dev/goatty/releases):

    ```bash
    sudo dnf install ./goatty-<version>-1.x86_64.rpm
    ```
  </TabItem>

  <TabItem label="Tarball (no root)" icon="seti:zip">
    Works on any distro. Extract the archive and run the installer. It puts `goatty` and `goattyd` in `~/.local/bin` and adds a launcher to your application menu:

    ```bash
    tar -xzf goatty-<version>-x86_64-linux.tar.gz && ./install.sh
    ```

    Add `~/.local/bin` to your `PATH` to start goatty from a terminal.
  </TabItem>
</Tabs>

Each release page lists the exact commands for that version.

## First launch

<Steps>
1. **Open goatty** from your application launcher, the Start Menu, or by running `goatty`.

2. **Take the welcome tour.**

   On the very first start goatty opens a short setup window: pick a theme and text size, install the shell tools (downloaded into goatty's own folder, no `sudo`), and choose whether to import the `PATH` your existing shell setup builds. Reopen it any time from the command palette: **Welcome and setup**.

3. **Start typing.**

   You get inline suggestions, live syntax highlighting, fuzzy history search on <kbd>Ctrl</kbd>+<kbd>R</kbd>, and a good prompt. See [Managed shell](/docs/using/managed-zsh).

4. **Open settings** with <kbd>Ctrl</kbd>+<kbd>,</kbd>.

   Use *Search settings* at the top to find anything by name or by what it does.
</Steps>

<Aside type="tip" title="Your dotfiles are safe">
  goatty never edits your `~/.zshrc` or other dotfiles. The one exception is opt-in: [Use goatty's shell in every terminal](/docs/using/managed-zsh#goattys-shell-in-every-terminal) adds a single guarded line to `.zshenv`, which you can remove again.
</Aside>

## The ideas to know

| Term | What it is |
| --- | --- |
| **Pane** | One terminal, with its own shell. Split a tab to get more. |
| **Tab** | A set of panes. |
| **Workspace** | A named set of tabs, shared by every window that shows it. See [Tabs, panes & workspaces](/docs/using/tabs-workspaces). |
| **goattyd** | The small background program that owns your shells, so they outlive the window. Starts by itself. |
| **Host** | A computer running goattyd: this one, or another over [SSH or Tailscale](/docs/using/remote-hosts). |

**Closing a window doesn't end your shells.** It *detaches*, and the next time you start goatty everything is back. To actually end a shell, close its pane or tab. See [Sessions & detaching](/docs/using/sessions).

## Shortcuts worth learning first

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Command palette: search every action |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | New tab |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> / <kbd>O</kbd> | Split right / down |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | [Snippets](/docs/using/snippets): find a command and fill it in |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Connect to another host |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copies when text is selected, interrupts otherwise |

Everything is rebindable. The full list is on the [shortcuts reference](/docs/reference/shortcuts).
